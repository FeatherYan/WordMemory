# 等待 AI 时背单词小组件：首版设计规格

## 目标与范围

为中国学术类雅思考生提供一个 Windows 桌面悬浮小组件，在等待 AI 工作时进行低打扰的英语词汇练习。

- 支持 Windows 10 / 11 64 位电脑。
- 使用简体中文界面、固定浅色主题和安静的学术笔记视觉风格。
- 首版为个人离线使用：无账号、无云同步、无遥测、无运行时网络请求。
- 首版不支持自动识别任意 AI 的等待状态；学习会话由用户手动开始和暂停。

## 窗口与会话

- 小组件有收起与展开两种状态。收起时仅显示可拖动的小图标；展开时显示约 380 × 500 像素的学习窗口。
- 两种状态共享同一位置锚点；窗口可缩放并记住位置与大小，展开时保持在可用屏幕范围内。
- 展开窗口才置顶。关闭按钮只收起窗口；用户从小图标右键菜单明确选择“退出”才结束程序。
- 不开机自启，用户手动打开应用。
- 默认全局快捷键为 `Ctrl + Alt + V`，可在设置中修改，用于切换收起与展开。
- 展开后先显示入口页，包含“开始学习”、今日新学数、今日复习数和设置入口。首次启动不设置向导。
- 开始会话后，如果中途收起，下一次点击“开始学习”将恢复同一张卡片、同一正反面。

## 学习卡与交互

- 首版只使用单个英文词作为目标项；固定搭配仅在答案面展示，不作为独立卡片。
- 一张卡只学习一个词性和一个语境义项；同词的其他重要义项以不同例句另建卡片。
- 提示面展示完整英文例句并高亮目标词，用户先根据语境主动回忆词义。
- 点击或按 `Space` 揭示答案面。答案面包含：
  - 整句中文翻译；
  - 目标词的词性与当前语境下的中文释义；
  - 与所选口音匹配的 IPA 音标和发音按钮；
  - 常见固定搭配。
- 评分只使用“记得”与“不记得”，没有输入作答、倒计时、自动翻面、抢焦点或通知。
- 支持鼠标和快捷键：`1` 记得、`2` 不记得、`M` 标记/取消标记、`Esc` 收起。
- 作答提交后不提供撤销机制。
- 标记仅能在当前展开的卡片上进行；不暂停出卡、不进入独立列表、也不填写备注。

## 发音

- 使用 Windows 本机 TTS；默认英式英语，可在设置中切换美式英语。
- 音标随口音同步切换。
- 缺少所选语音时，应用只提供“打开 Windows 语音设置”入口；由 Windows 设置联网下载语音，应用本身不联网。

## 复习与队列

- 所有复习以日历天数计时；错过学习日不会重置进度，到期卡在下一次学习时优先出现。
- 队列先出到期复习卡，之后才引入新词。
- 固定复习阶梯：
  - 不记得：本会话隔 5 张卡重现，并在次日到期；
  - 连续记得：分别在 3、7、14、30、60 天后复习。
- 每日到期复习默认显示最多 20 张；用户可主动继续清理积压，但积压时不引入新词。
- 每日新词目标可设置，默认 10 张，仅为软性目标，可无限继续学习新词。
- 当没有到期卡且没有新词时，用户可从提示页手动启动自由复习。自由复习随机使用已学卡，作答不修改正式到期计划。
- 设置中只显示当日新学数与复习数；不提供连续打卡、积分、徽章、排名或掌握率。
- 首版不提供重置进度功能。

## 词包与内容

- 首版内置一个独立、版本化的试点词包，含 600 张完整语境卡：480 张基础高频词与 120 张学术雅思词。
- 候选范围以个人使用的雅思词汇参考为主；NGSL / NAWL 仅用于基础高频和学术优先级标注，不自动扩充候选范围。
- 卡片保留雅思主题标签（如教育、环境），默认按复习优先级与重要性混合出卡；主题仅供未来主动筛选。
- 词包制作采用离线流程：AI 辅助补齐缺失内容、自动检查字段与语境一致性、用户抽样复核后发布到词包。学习期间不联网生成内容。
- 词典条目与学习卡分离：词典条目保存词形、音标、词性和义项；学习卡绑定具体义项、例句和答案详情。

## 本地数据与备份

- 使用独立的本地内容包和学习档案。替换或更新词包不应清除学习进度。
- 学习档案保存词库选择、复习记录、设置与窗口布局。
- 设置中提供学习档案的手动导出和导入恢复；备份不包含词包本体。
- 首版不提供词包导入界面；后续可在不影响学习档案的前提下添加。

## 技术与交付

- 使用 .NET 8 WPF 构建 Windows 桌面界面，并使用 SQLite 保存内容与本地状态。
- 以免安装、自包含的便携程序交付；解压后直接运行，无需额外安装 .NET 运行时。
- 首版不支持 macOS、移动端、32 位 Windows、自动 AI 等待感知、云同步、账号、在线词典 API 或应用内内容编辑。
